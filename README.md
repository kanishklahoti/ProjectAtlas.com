# PROJECT ATLAS — Urban Intelligence Simulator

An interactive browser prototype for the BIOFLOW P.U.L.S.E. urban traffic optimisation framework.

## Launch

Open `index.html` in any modern browser. No install or server is required.

For the best local development experience, serve the folder with any static web server, then open its local address.

## What is included

- Interactive animated road-network digital twin with vehicles, signals, sensors, road incidents and emergency vehicle mode.
- Scenario controls: morning peak, closure, emergency priority, air quality event and stadium release.
- Adjustable traffic demand, environmental priority and agent coordination.
- Nine selectable simulation modules: Physarum, shortest/emissions routing, ant-colony, multi-agent coordination, digital twin, self-healing, emergency corridor, reservation intersection and reversible lanes.
- Live model readouts and a comparison chart explicitly labelled as simulated outputs.
- An in-map legend and model-specific explainer that tells the viewer exactly what to look for as each model is selected.
- Configurable brand switcher between `BIOFLOW` and `BioTecFlow`.

## Scope note

This is a visual, computational prototype for evaluation and demonstration. Its outputs are modeled from the in-app settings and are not real-world traffic, carbon, safety or operational validation.
